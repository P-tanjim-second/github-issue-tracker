<summary>1️⃣ What is the difference between var, let, and const</summary>

**Answer:**
first of all **const** and **let** is a **block scope variable declare method**. This two variable declare method do **hoisting** but not initialized so we can't access them before initialize and get error. Also for block scope if we declare those in any block it can't be use outside the block and we can't reuse same variable name for varible declare. We can reassign **let** variable value but can't do it in **const** method. **Const** make variable **Constant**. On the other hand **var** is **function scope** so if we declare it inside a funciton we can't access it outside the function. but if we declare **var** outside for hoisting we can use it before initialize and it will give **undefined**. Also in **var** we can also use same variable name for multiple variable declaration.

<summary>3️⃣ What is the difference between map(), filter(), and forEach()</summary>

**Answer:**
These 3 things are **methods of array**. We used them for different use cases.
We use **map()** to apply any logic to every element in an array and create another array with those new values.
**filter()** is used for filtering any element that matched to the condition we give inside **filter()** method. It also returns a **new array**.
At last we use **forEach()** method to do something with the array elements. It returns **undefined**.

</details>

<summary>4️⃣ What is an arrow function</summary>

**Answer:**
An **arrow function** is ES6 **syntax** for writing function using `=>` operator. It makes the code **clean** and provides **lexical scoping for `this`**.
